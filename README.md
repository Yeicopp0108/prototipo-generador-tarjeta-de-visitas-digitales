# prototipo-generador-tarjeta-de-visitas-digitales
Single Page Application (SPA) que permite a los usuarios generar tarjetas de visita digitales interactivas. A partir de unos datos introducidos en un formulario, la aplicación renderiza una vista previa de la tarjeta profesional, genera un código QR con la información de contacto en formato vCard (para que al escanearlo con un móvil).
